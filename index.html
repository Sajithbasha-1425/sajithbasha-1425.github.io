    Global Energy Intelligence Dashboard

    An interactive dashboard for historical global energy data.

    GitHub repository

    Dashboard walkthrough

    Video not playing? Open it in a new tab.

    Project overview

    A browser dashboard for exploring historical oil, natural-gas and coal production and consumption records. It combines data validation, a responsive dark-theme layout, interactive charts, country and year filtering, automatic insights, a searchable data preview and CSV export.

    Business objective

    Make long-run energy history easy to explore by dataset, country and year, and turn the current filter into clear KPIs and plain-language insights without opening a spreadsheet.

    Workflow

    1. Data collectionSix CSV datasets
    2. Data cleaningDuplicate and blank checks
    3. Data transformationFilter-based KPIs and averages
    4. Data analysisGenerated insights
    5. Dashboard developmentCharts, table, export
    6. Business insightsTrends and rankings

    Dataset information

    Figures from the repository’s data quality report. Entries include countries and regional groupings.

    DatasetRows after cleaningYearsUnitDuplicate country-yearsNegative valuesBlank country or year

    Data preparation and cleaning

    • Each dataset is a separate file with country, year and a unit-specific value column.
    • Duplicate country-year records are handled in the supplied cleaned files.
    • A data quality report documents rows, year range, units, duplicates, negative values and blanks for every file.
    • All six files show zero duplicates, zero negative values and zero blank countries or years after cleaning.

    Analysis methodology

    • KPI cards recalculate for the chosen dataset, country and year.
    • Insights are generated automatically: change between the first and last available annual averages, the year with the highest annual average, and the top country in the latest selected year.
    • Methodology, units and limitations are documented in the repository.

    Features in the repository

    Tools and technologies

    • HTML
    • CSS
    • JavaScript
    • Chart.js
    • Three.js
    • CSV data
    • GitHub Pages

    Challenges and solutions

    • Different coverage: gas production starts in 1970 and coal production in 1981, while the others start in 1965. The record-coverage chart shows this directly.
    • Different units: oil in thousand barrels a day, gas in bcm, coal in exajoules or million tonnes. Each dataset keeps its own unit.
    • Repeated country-year rows: handled and verified in the cleaned files.
